Automate your network reconnaissance with ease.

## Features
The `noyouarerude` repository provides a comprehensive toolkit for network discovery and exploration. The included Maigret tool allows you to:

* Perform DNS lookups and gather information about target hosts
* Identify open ports and services on remote machines
* Gather system information, including OS, IP addresses, and more

## Tech Stack
- Maigret (0.6.1)

## Installation
To get started, simply extract the `maigret-0.6.1.zip` file to a directory of your choice. Then, follow the instructions provided with the Maigret tool for installation and configuration.
